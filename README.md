# Aplikasi Belajar Pintar CLI Untuk Membantu Murid Sesuai Mata Pelajaran

## 1. Deskripsi Singkat
Project ini adalah aplikasi pembelajaran berbasis CLI menggunakan Python.
Program ini memiliki sistem soal, streak belajar, dan pengingat belajar berdasarkan hari.

## 2. Fitur Utama
- Menu interaktif
- Soal latihan
- Sistem streak belajar
- Pengingat belajar sesuai hari
- Penyimpanan data streak ke file

## 3. Cara Menjalankan Program
1. Download semua file pada repository
2. Buka aplikasi Pydroid 3 / Python
3. Jalankan file:
   python Belajar_Pintar.py

## 4. Struktur Folder/File
- tes2.py → Program utama aplikasi
- streak.txt → Menyimpan data streak pengguna
- README.md → Dokumentasi project
